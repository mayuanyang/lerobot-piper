- 完整解析了 `src/models/wilro`（WilroTransformer）并输出详细架构分析报告（带图）。
- wilro = SmolVLM2-500M 冻结编码器 + 16 层可训练 DiT 解码器的 encoder-decoder 流匹配 VLA（π0 风格 MoT，cross-attention 读 VLM KV cache，与 wiltechs_x 的 joint self-attention 路线不同）。
- 关键点：KV cache 恒 detach（text 路径零梯度）；视觉 LoRA（SigLIP 后 8 层）仅通过 Robot CA 旁路（SigLIP 第 -3 层中间特征）接收流匹配 MSE 梯度；无离散动作头/CE；对比损失用 KV 语言槽置换 + hard negatives（Jaccard）；10 步去噪无 shortcut；config horizon=4/n_action_steps=4（ARCHITECTURE.md 的 H=64 已过时）。
- 用户在持续对比学习 wiltechs_x vs wilro 两条架构路线，讲解需初学者友好 + 图示。
- 澄清 wilro Robot CA 双重角色：前向=动作 query 读 SigLIP 第-3层高分辨率特征；反向=DiT→SigLIP LoRA 的唯一梯度通路（KV cache 被 detach，此路是唯一活线），梯度穿过第-3层继续回传至第19-26层所有 LoRA 适配器（wilro_model.py:857-860 注释确认）。
- 讨论 wilro DiT 能力边界：DiT 学的是『任务导向的特征重组/解读』（affordance、指令→行为映射、操作尺度空间推理），不学通用 vision/language 能力——它从未见过原始像素和 token，天花板由冻结编码器的特征空间决定；SmolVLM2-500M 语言理解弱意味着复杂指令失败发生在编码器侧而非 DiT 侧；视觉 LoRA 是唯一轻微撑宽瓶颈的手段。
